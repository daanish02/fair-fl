### Corrections found by the specs (apply before any reproduction run)
- **FCFL:** the first suite was stopped because it doesn't match the paper. The fixes:
  - α (`eta`) = 0.3 as in the paper, not the code default 0.5;
  - the code's per-client split is 80/10/10, unshuffled, not 8:2;
  - the paper's "Accuracy" is on the **global official MNIST test set**, so the engine must also evaluate the global model on it (with `data.source: train`, keep the official test set as a global test set). Variance and worst-10% are across clients;
  - there is no server momentum; the client momentum of 0.5 is correct.
  - Targets (Table 2): MNIST FedAvg 95.96 (variance 15.06), FCFL 96.06 (variance 11.03, worst-10% 89.17).
- **LoGoFair:** the official code is github.com/liizhang/LoGofair (lg_client.py and lg_du.py in the scratchpad are byte-identical). It uses:
  - Adam, lr 0.005, batch 512, 40 local steps, 25 rounds;
  - β = 1000, post-processing lr 0.005, 30 post rounds;
  - validation = the whole 70% training split, Dirichlet with 2·α, δ = 0.02.
  - Target (Table 1): FedAvg on Adult at α = 0.5 gets 0.8381 / 0.1922 / 0.1759. The repo also ships the α = 0.5 split and a pre-trained model.
- **FairWeight:** β1 = 1.5 and β2 = 100 are fixed in the code. The loss has a double sigmoid, and the potential outcomes are misaligned (see `docs/repro/fairweight.md`). Target: FedAvg on Adult gets accuracy 0.77, balanced accuracy 0.79, DP 0.409 (Table II).
- **FedFDP:**
  - Dir(0.1), 10 clients, all participating every round;
  - learning rate 1.0 with DP, 0.1 without;
  - one DP step per round with Poisson sampling q = 0.05;
  - C = 0.1, σ = 2, loss-clip initial value 2.5, σ_l = 5, δ = 1e-5; ε = 3.52 means about 776 rounds.
  - Target: MNIST FedAvg 93.40 vs FedFDP 95.13 (Table 3).
- **Median:** the only medianSGD experiment in the paper is a 1-D toy problem; its neural-network experiments are signSGD only. See `docs/repro/median.md`.
- The FedCDA/FedMut/FairRFL spec agent was still running at handoff time.
