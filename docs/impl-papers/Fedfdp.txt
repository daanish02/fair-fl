2. PROBLEM SETUP
--------------------------------------------------------------------------------
The paper targets "balanced performance fairness" in federated learning (FL) —
explicitly NOT demographic/group fairness (not about protected attributes like
gender/race). Balanced performance fairness (Definition 1, citing Li et al. [25],
q-FFL) means: model w1 is "more fair" than model w2 if w1's performance is more
uniform across the N client devices. The paper operationalizes this via the
*variance of per-client loss* (not accuracy variance, which prior work [28] used);
using loss variance lets the fairness metric be folded directly into the training
objective for iterative optimization. The fairness metric Psi(w) is the weighted
variance of client loss values under the globally trained model w (Eq. 2, Section
2.1).

The privacy threat model is standard central/local differential privacy (DP) for
FL under the (epsilon, delta)-DP definition (Definition 2, Eq. 3), instantiated
via DP-SGD (Abadi et al. [1]): per-sample gradient clipping (sensitivity control)
plus calibrated Gaussian noise addition, analyzed under Renyi Differential Privacy
(RDP, Mironov [32], and RDP of the sampled Gaussian mechanism, Mironov et al.
[33]), then converted to (epsilon,delta)-DP via Lemma 1. The paper explicitly
does NOT assume Secure Aggregation (SecAgg) — the server can observe individual
client uploads (model updates and loss values) in the clear; DP is what protects
against the server seeing sensitive info in those uploads. The paper states DP is
guaranteed at "sample-level" via per-sample clipping, and notes SecAgg is
orthogonal (could be added but isn't assumed and doesn't replace DP).

The core technical problem: achieving fairness requires clients to upload extra
information (per-client loss values) to the server, and the local loss-reweighting
mechanism used for fairness interacts with DP's clipping/noise mechanics — both of
which can hurt fairness, privacy budget, or model utility if not co-designed. The
paper's contribution is a unified algorithm that co-designs (a) a fairness-aware
local objective, (b) DP-SGD-compatible fairness-aware per-sample gradient clipping,
and (c) an adaptive (privacy-budget-saving) clipping scheme for the uploaded loss
values.

3. ALGORITHM

3A. BASE QUANTITIES (Section 2.1, Eq. 1-2)
--------------------------------------------------------------------------------
Global FL objective:
    w* = argmin F(w),  F(w) = sum_{i=1}^{N} p_i * F_i(w)        (Eq. 1)
where F_i(.) is client i's local loss function, and p_i = |D_i| / sum_j |D_j|
(client weight proportional to local dataset size), D_i = client i's dataset.

Fairness metric (weighted variance of client loss under global model w):
    Psi(w) = sum_{i=1}^{N} p_i * (F_i(w) - F(w))^2               (Eq. 2)
Lower Psi = fairer (more uniform per-client loss).

Standard DP-SGD background given (Section 2.2, Eq. 3-5), used as the baseline
mechanism FedFDP extends:
    g_t^{i,j} = grad F_i(w_t^i, xi_j)                             per-sample grad
    clipped: g_hat_t^{i,j} = g_t^{i,j} / max(1, ||g_t^{i,j}|| / C)  (Eq. 4)
    noised batch update: g_tilde_t^i = (1/|B_i|) * (sum_j g_hat_t^{i,j} + C*sigma*N(0,I))
                                                                    (Eq. 5)
    C = clipping bound, sigma = noise multiplier, B_i = client i's batch.

3B. FEDFAIR (Algorithm 1; Section 3; Eq. 6-9)
--------------------------------------------------------------------------------
Combines the FL objective (Eq. 1) with the fairness metric (Eq. 2) into one
objective:
    min_w H(w) = F(w) + (lambda/2) * sum_{i=1}^{N} p_i * (F_i(w) - F(w))^2   (Eq. 6)

Per-client, per-round refined local objective (client i, round t):
    min_{w_t^i} H_i(w_t^i) = F_i(w_t^i) + (lambda/2) * (F_i(w_t^i) - F(w_t^i))^2
                                                                    (Eq. 7)
Here F(w_t^i) = sum_{k=1}^{N} p_k F_k(w_t^k) is the PREVIOUS round's broadcast
global loss (computed server-side from training data of round t-1, per Algorithm 1
line 16/line 7 — footnote 4 clarifies F(w_t) != F(w_t, test data) because the
server cannot use held-out test data to compute it; it's purely a function of
the training losses reported by clients in the prior round). F(w_t^i) is treated
as a CONSTANT when differentiating H_i with respect to w_t^i.
lambda >= 0 is the fairness hyperparameter: lambda=0 recovers vanilla FL
(FedAvg-like); lambda -> infinity makes the algorithm focus purely on fairness
(paper notes very large lambda causes steep gradients that can prevent
convergence — motivating the optimal-lambda derivation in Section 5).

Gradient of Eq. 7 (treating F(w_t^i) as constant):
    grad H_i(w_t^i) = (1 + lambda * Delta_i) * grad F_i(w_t^i)      (Eq. 8)
    where Delta_i = F_i(w_t^i) - F(w_t^i)

SGD update using Eq. 8:
    w_{t+1}^i = w_t^i - eta*(1 + lambda*Delta_i)*grad F_i(w_t^i)
              = w_t^i - eta_i * grad F_i(w_t^i)                     (Eq. 9)
    where eta_i = eta * (1 + lambda * Delta_i)

Interpretation: this is a DYNAMIC (per-client, per-batch) learning rate eta_i that
scales the base rate eta by (1 + lambda*Delta_i) — the exact "local scaling
factor" the task asked about. Clients whose local loss F_i exceeds the broadcast
global loss F (i.e., underperforming clients, Delta_i > 0) get a boosted
effective learning rate; clients doing relatively well (Delta_i < 0) get a damped
rate — pushing the system toward uniform per-client loss.

Algorithm 1 (FedFair), full procedure:
  Input: loss function F(w), learning rate eta, fairness hyperparameter lambda,
         batch sample ratio q, local dataset D_i.
  Output: final trained model w_T
  SERVER:
    for t = 0..T-1:
      for i = 1..N (parallel):
        w_{t+1}^i, F_i(w_{t+1}^i) = LOCAL(w_t, F(w_t))
      w_{t+1} = sum_i p_i * w_{t+1}^i
      F(w_{t+1}) = sum_i p_i * F_i(w_{t+1}^i)
    return w_T
  LOCAL:
    Download w_t, F(w_t); set w_t^i <- w_t
    Split D_i into batches {B_i}
    for batch b in {B_i}:
      Delta_i = F_i(w_t^i, b) - F(w_t)
      eta_i = eta * (1 + lambda * Delta_i)
      w_t^i = w_t^i - eta_i * grad F_i(w_t^i, b)
    w_{t+1}^i <- w_t^i; compute F_i(w_{t+1}^i)
    return w_{t+1}^i, F_i(w_{t+1}^i)

Note server broadcasts BOTH w_t and the scalar F(w_t) every round (communication
overhead: O(d) for model params + 1 scalar — see Table 1 in Section 4).

3C. FEDFDP (Algorithm 2; Section 4; Eq. 10-15)
--------------------------------------------------------------------------------
FedFDP = FedFair + DP. Two DP mechanisms are added: (1) fair-clipping for
per-sample gradients (Section 4.1), (2) adaptive clipping for the uploaded loss
value (Section 4.2). Figure 1 (page 9) gives the full pictorial flow: server
broadcasts w_t and F(w_t); client i updates locally via "Fair-Clipping" + noise on
gradients, and separately clips+noises its own loss before uploading; server
aggregates both the model (weighted mean) and the loss (weighted mean) to get
w_{t+1} and F(w_{t+1}).

Per-sample expansion of the FedFair objective (needed because DP-SGD requires
PER-SAMPLE clipping, not per-batch):
    min_{w_t^i} H_i(w_t^i, xi_j) = F_i(w_t^i, xi_j)
        + (lambda/2) * (F_i(w_t^i, xi_j) - F(w_t^i))^2              (Eq. 10)
    where xi_j in B_t^i, j = 1..|B_i|, |B_i| = client i's batch size.

Gradient of Eq. 10:
    grad H_i(w_t^i, xi_j) = (1 + lambda * Delta_i^j) * grad F_i(w_t^i, xi_j)
                                                                      (Eq. 11)
    where Delta_i^j = F_i(w_t^i, xi_j) - F(w_t^i)     [per-SAMPLE delta, note the
                                                        superscript j vs Eq. 8's
                                                        per-batch Delta_i]

To make this DP-SGD-compatible, the paper replaces the raw gradient in the
descent step with the fairness-reweighted gradient of Eq. 11 and applies
per-sample clipping to IT (not to the raw gradient), giving the full FedFDP
local update:

    w_{t+1}^i = w_t^i - (eta/|B_i|) * [ sum_{j=1}^{|B_i|} C_t^{i,j} * grad F_i(w_t^i, xi_j)
                                         + sigma*C * N(0,I) ]        (Eq. 12)

where the fair-clipping coefficient is:
    C_t^{i,j} = min( 1 + lambda*Delta_i^j,  C / ||grad F_i(w_t^i, xi_j)|| )  (Eq. 13)

This is the EXACT quantity the task asked about: "C_ij = min(1 + lambda*delta,
C/||g_j||)" — confirmed verbatim as Eq. 13, with Delta_i^j = F_i(w_t^i,xi_j) -
F(w_t^i) (the per-sample loss minus the broadcast global loss from the previous
round).

Interpretation given by the paper (Section 4.1, directly below Eq. 13): this is
called a "fair-clipping" technique.
  - When lambda = 0, Eq. 13 reduces to standard DP clipping without fairness
    (C_t^{i,j} = min(1, C/||grad||)).
  - For LARGE C, Eq. 13 simplifies to the first term (1 + lambda*Delta_i^j) —
    i.e. the fairness-scaling term dominates and the clip rarely binds.
  - For SMALL C, Eq. 13 simplifies to the second term (C/||grad||) — i.e.
    gradients get clipped to the DP bound C regardless of fairness scaling.

Fair-clipping DPSGD steps (Section 4.3 "Overall Algorithm", summarizing lines
11-15 of Algorithm 2): compute fair-clipping bound C_t^{i,j} (Eq. 13) and
per-sample gradient grad F_i(w_t^i, xi_j) to get processed gradient g_tilde_t^{i,j}
= C_t^{i,j} * grad F_i(w_t^i, xi_j); add mean-0 Gaussian noise sigma*C*N(0,I) to
the SUM of processed per-sample gradients (once per batch, not per-sample); then
gradient-descend.

ADAPTIVE LOSS-UPLOAD CLIPPING (Section 4.2, Eq. 14-15; Algorithm 2 lines 16-20)
--------------------------------------------------------------------------------
Motivation stated by the paper: computing Delta_i^j requires clients to upload
F_i(w_t^i) to the server every round, which itself needs DP protection (it
touches private training data). F_i(w_t^i) must be clipped to interval
[0, C_l^{i,t}] then Gaussian-noised with std sigma_l * C_l^{i,t} before upload.
Because client loss distributions are heterogeneous (non-IID), a FIXED clip bound
is bad: too large adds excessive noise, too small aggressively clips and loses
signal — hence an ADAPTIVE, per-client, per-round clip bound.

The adaptive clipping method uses the "differentially private mean of the
PREVIOUS round" as this round's clip bound. For client i, round t:

    C_l^{i,t} = [ sum_{j=1}^{|B_i|} clip(F_i(w_{t-1}^i, xi_j)) + N(0, (C_l^{i,t-1} * sigma_l)^2) ]
                / |B_i|                                              (Eq. 14)

where:
    clip(F_i(w_{t-1}^i, xi_j)) = min( C_l^{i,t-1}, max(0, F_i(w_{t-1}^i, xi_j)) )
                                                                       (Eq. 15)

i.e. C_l^{i,t} is a noised, averaged, clipped version of the PREVIOUS round's
per-sample losses, using the PREVIOUS round's own clip bound C_l^{i,t-1} and
noise multiplier sigma_l^{t-1}. The paper states this preserves DP by the
post-processing property (since C_l^{i,t} is derived from already-DP-protected
quantities, further use of it doesn't cost additional privacy budget).

Algorithm 2 lines 17-20 (the actual loss-upload procedure per round, using the
CURRENT round's clip bound C_l^{i,t} computed via Eq. 14-15):
    for j = 1..|B_i|:
      compute F_i(w_{t+1}^i, xi_j)
      f_{i,j} = min( C_l^{i,t}, max(0, F_i(w_{t+1}^i, xi_j)) )
    F_tilde_i(w_{t+1}^i) = (1/|B_i|) * [ sum_j f_{i,j} + sigma_l * C_l^{i,t} * N(0,I) ]
    return w_{t+1}^i, F_tilde_i(w_{t+1}^i)

This F_tilde_i(w_{t+1}^i) (DP-protected, noised, clipped loss estimate) is what's
actually uploaded to and aggregated by the server (server computes
F(w_{t+1}) = sum_i p_i * F_tilde_i(w_{t+1}^i), Algorithm 2 line 6), replacing the
noiseless F_i(w_{t+1}^i) used in FedFair's Algorithm 1.

FULL ALGORITHM 2 (FedFDP), as printed:
  Input: loss function F(w), learning rate eta, noise multiplier for gradient
         sigma, noise multiplier for loss sigma_l, fairness hyperparameter lambda,
         batch sample ratio q, original clipping bound C.
  Output: final trained model w_T
  SERVER:
    for t = 0..T-1:
      for i = 1..N (parallel):
        w_{t+1}^i, F_tilde_i(w_{t+1}^i) = LOCAL(w_t, F(w_t))
      w_{t+1} = sum_i p_i * w_{t+1}^i
      F(w_{t+1}) = sum_i p_i * F_tilde_i(w_{t+1}^i)
    return w_T
  LOCAL:
    Download w_t, F(w_t); set w_t^i <- w_t
    Sample a batch B_i randomly WITH PROBABILITY q   [Poisson sampling — this is
                                                        the exact mechanism, "q" is
                                                        the per-example inclusion
                                                        probability used in the RDP
                                                        sampled-Gaussian analysis]
    for j = 1..|B_i|:
      Delta_i^j = F_i(w_t^i, xi_j) - F(w_t)
      compute C_t^{i,j} via Eq. 13
      g_tilde_t^{i,j} = C_t^{i,j} * grad F_i(w_t^i, xi_j)
    w_{t+1}^i = w_t^i - (eta/|B_i|) * (sum_j g_tilde_t^{i,j} + sigma*C*N(0,I))
    compute loss clipping bound C_l^{i,t} via Eq. 14-15
    for j = 1..|B_i|:
      compute F_i(w_{t+1}^i, xi_j)
      f_{i,j} = min(C_l^{i,t}, max(0, F_i(w_{t+1}^i, xi_j)))
    F_tilde_i(w_{t+1}^i) = (1/|B_i|)*(sum_j f_{i,j} + sigma_l*C_l^{i,t}*N(0,I))
    return w_{t+1}^i, F_tilde_i(w_{t+1}^i)

OPTIMAL FAIRNESS PARAMETER lambda* (Section 5, Theorem 1 Eq. 16, Section 5.1
Eq. 17-22)
--------------------------------------------------------------------------------
Theorem 1 (simplified convergence bound, full version = Theorem 5 in Appendix):
    E[F(w_T)] - F* <= O(L*G^2*lambda^2 / (mu^2*T))
                     + O(L^2*Gamma*lambda / (mu^2*T))
                     + O(L*sigma^2*C^2*d / (mu^2*T*lambda))
                     + O(L*E||w_1-w*||^2 / T)                        (Eq. 16)
where L = smoothness constant (Assumption 1), mu = strong-convexity constant
(Assumption 2), G = bound on per-sample gradient norm (Assumption 3), Gamma =
heterogeneity measure (= F* - sum_i p_i F_i*, larger = more non-IID, consistent
with Li et al. [26]'s FedAvg non-IID convergence analysis), d = model dimension.

The paper shows lambda has a CONVEX influence on the convergence rate (Eq. 16:
one term grows with lambda^2, one shrinks with 1/lambda), so there's an interior
optimum. Section 5.1 derives this optimum analytically: assuming Delta_i^j is
bounded (Q0 <= Delta_i^j <= Q1, so 1+Q0*lambda <= C_t^{i,j} <= 1+Q1*lambda), the
upper bound becomes a rational function P(lambda) = (L/2muT) * (a1*lambda^3 +
a2*lambda^2 + a3*lambda + a4)/(a5*lambda+1) (Eq. 17), with a1..a5 defined in terms
of G, Q0, Q1, L, Gamma, sigma, C, d, ||w1-w*||^2 (full definitions on page 10).
Minimizing via calculus (derivative F'(lambda), Eq. 18; cubic G(lambda), Eq. 19;
discriminant argument, Eq. 20-21; depressed-cubic substitution and Cardano's
formula, Eq. 22) yields closed-form roots x1,x2,x3 and the conclusion: G(lambda)
has exactly one positive real root among any real roots, and lambda* =
max_m(lambda_m) over the real roots.

IMPORTANT CAVEAT (stated explicitly by the paper itself, Section 7.4 "Impact of
Different lambda", page 18): this closed-form lambda* "relies on constants or
upper bounds (e.g., L, mu, G, Gamma) whose specific values change with different
models, datasets, and loss functions" — i.e., the paper does NOT give a usable
numeric lambda* for its experiments; it only confirms empirically (Fig. 2, Section
7.4) that an interior optimal lambda exists, by sweeping lambda and observing
non-monotonic Psi. Do not treat lambda* as a reportable number — the paper
provides no closed numeric value for it, only the shape of the relationship.

5.1 PRIVACY GUARANTEE (Section 6, Theorems 2-4, Lemma 1)
--------------------------------------------------------------------------------
FedFDP provides formal (epsilon,delta)-DP, derived via RDP:
  - Theorem 2 (Eq. 23): RDP of the model update w_T^i after T rounds of local
    updates, R_model^i(alpha) = T/(alpha-1) * log(sum_{k=0}^alpha C(alpha,k) *
    (1-q)^(alpha-k) * q^k * exp((k^2-k)/(2*sigma^2))), alpha>1 the RDP order.
    (Uses the "Sampled Gaussian Mechanism" RDP result of Mironov et al. [33],
    Definition 3, Eq. 24-26.)
  - Theorem 3 (Eq. 27): RDP of the uploaded loss F_tilde_i(w_{t+1}^i), same
    functional form as Theorem 2 but with sigma_l in place of sigma:
    R_loss^i(alpha) = T/(alpha-1) * log(sum_k C(alpha,k)*(1-q)^(alpha-k)*q^k*
    exp((k^2-k)/(2*sigma_l^2))).
  - Theorem 4 (Eq. 28): combines model-update RDP and loss RDP SEQUENTIALLY
    (composition, Definition 4) then converts to (epsilon,delta)-DP via Lemma 1
    (RDP-to-DP conversion, Balle et al. [3]):
    (epsilon^i, delta^i) = (R_model^i(alpha) + R_loss^i(alpha) + ln((alpha-1)/alpha)
                             - (ln(delta)+ln(alpha))/(alpha-1), delta)
    for any 0 < delta < 1.
  - The realized experimental privacy budget reported throughout Section 7 is
    epsilon = 3.52 at delta = 1.0e-5 (default setting), with other epsilon
    values (1,2,3,4) explored in Table 6's ablation and epsilon as an OUTPUT
    (not input) in Table 7's target-accuracy experiments.
  - FedFDP explicitly does NOT assume Secure Aggregation; sample-level DP via
    per-sample clipping is the sole protection mechanism (Section 6 opening
    paragraph).

5.2 CONVERGENCE ANALYSIS ASSUMPTIONS (Appendix A.1, used for Theorem 1/5)
--------------------------------------------------------------------------------
  - Assumption 1: F_1..F_N are all L-smooth.
  - Assumption 2: F_1..F_N are all mu-strongly convex.
  - Assumption 3: per-sample stochastic gradient norm uniformly bounded by G,
    i.e. ||grad F_i(w_t^i, xi_j)|| <= G for all i,t,j.
  These are standard convex-optimization assumptions for the theoretical
  analysis; the paper's actual CNN experiments are non-convex (the assumptions
  are a theoretical convenience for Theorem 1/5, not a claim the experiments
  satisfy them).

Theorem 5 (full, unsimplified convergence bound, Eq. 29, Appendix A.2):
    E[F(w_t)] - F* <= (L/2t) * ( A/(mu^2*(2*C_t - 1)) + E||w_1-w*||^2 )
  where A = G^2*C_t^3 + 3*G^2*C_t^2 + 2*L*Gamma*C_t + 2*sigma^2*C^2*d/B_hat^2,
  B_hat = min_i |B_i| (smallest client batch size), Gamma = F* - sum_i p_i*F_i*
  (non-IID heterogeneity measure), C_t = sum_i p_i*C_t^i, C_t^i = (1/|B_i|) *
  sum_j C_t^{i,j} (i.e. C_t is the batch/population-average of the per-sample
  fair-clipping coefficients). Full derivation (Lemma 2 and its proof, virtual
  sequences v_t, w_t) spans Appendix A.2, pages 25-30 — purely theoretical, not
  needed for config-building but included here for completeness/citation
  accuracy.

5.4 LIMITATIONS STATED BY THE PAPER (Section 8, verbatim themes)
--------------------------------------------------------------------------------
  - Only statistical heterogeneity (non-IID data via Dirichlet) is studied; MODEL
    heterogeneity (different client architectures/capacities) and cross-domain
    data (differing feature spaces across clients) are NOT addressed.
  - Assumes full client participation every round; does NOT handle stragglers,
    device heterogeneity, unstable networks, or asynchronous updates — these are
    named as future work, not supported by the current algorithm/experiments.

5.5 RELATED WORK CONTEXT (Appendix B, brief)
--------------------------------------------------------------------------------
Distinguishes "group fairness" (demographic-attribute fairness, e.g. equal
opportunity — prior DPFL works like [14,15,34,9,10,37]) from this paper's target,
"balanced performance fairness" (uniform per-client performance, introduced by Li
et al. [25]/q-FFL, extended by [23,42]). Paper claims to be the first to address
balanced performance fairness specifically within DPFL (DP + FL combined).
